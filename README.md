# FrameLab R11 / Milanote-Reference V0.1

独立本地交互原型，2026-10-27。没有修改、读取或迁移 R10 用户数据。

## 启动

Windows 双击 `Start-R11.cmd`。已安装 Node.js 时在 http://127.0.0.1:4311 使用；没有 Node 时可直接双击 index.html 离线打开。建议 HTTP 方式获得稳定的本地存储来源和 Service Worker 缓存。关闭服务窗口停止服务。

本地使用无构建步骤、无第三方运行依赖，所有示例照片在 assets 中。工具准备包里的 React、Vite、Motion、Panzoom 等为后续工程化可用依赖；本版本没有假称全部采用。

局域网：手动运行 `node server.mjs --lan`，手机访问 `http://电脑局域网IP:4311`。如 Windows 弹出防火墙提示，由用户按实际网络环境选择。这里不自动改防火墙。手机默认简化项目列表。各设备浏览器各自保存数据，不自动同步；使用 JSON 备份交接。普通局域网 HTTP 的 Service Worker 通常不可用，但静态页面访问可用。

## 已实现

- 固定完整顶栏、窄工具栏、可切换浅深主题、线性/手绘线条试验。
- 无限点阵桌面、动态点密度、30 个示例照片项目、移动功能区。
- 点击选择、Shift 多选、空白拖动框选、多选一起拖动、Space+左键/中键平移、Ctrl+滚轮鼠标锚定缩放。普通滚轮平移。
- 无人工相纸边框，反色细选框、右下角斜线缩放；拖动轻微 rotateY，静止保持按键时也归正；尊重减少动态效果偏好。
- 新建、编辑、复制、置顶、删除至回收站、恢复、撤销/重做、方向键移动。
- Image、Note、Column、Board、Link、To-do、Line 对象。Board 当前是可编辑内容画板弹窗，不是独立嵌套无限桌面。Line 当前可调整的独立线段，尚未实现对象端点绑定。
- 本地上传照片、自动缩小至最长 1400px JPEG、本地存储、JSON 备份导出和校验导入、导入前自动下载旧备份。
- 三级语义缩放阈值缓冲、500ms 镜头定位、远处区域提示、操作时出现的小地图，停止后淡出。
- 模板创建内容画板；照片文件导出交给 Photoshop；手机项目列表。

## 数据

独立键：`framelab:r11:v1:desk`。不访问 R10 的旧键。清理浏览器数据或使用不同来源会导致内容不可见，务必定期导出备份。localStorage 的容量随浏览器变化，大量照片可能超过配额；保存失败会显示错误，当前内存内容仍可导出。此版尚未接入 IndexedDB 图片库和自动跨设备同步。

## V0.2 更新（2026-10-29）

照片选框贴合图片外围并随轻微透视变化，增强静止、选中与拖动阴影。工具栏按用户截图调整为窄灰底、白色小图标卡片与蓝色工具选中状态，支持拖出预览、桌面落位。蓝色仅用于工具栏，照片选择保持黑白反色。

从照片右上角手柄拖向另一个对象建立箭头连接；也可点击 Line 后依次点两个对象。连接会跟随端点移动和调整尺寸，随桌面一起缩放。点击连线显示中点，拖动调整曲率；选中后 Delete 删除，Ctrl+Z 撤销。连接数据随本地保存及 JSON 备份保存；删除端点时隐藏关联线，恢复端点后恢复显示。

Comment 是本地评论卡片，Table 是可编辑文本分隔行列渲染的基础表格，未接入多人评论或电子表格计算。此版不包含原站 Draw 自由绘图工具，工具栏像素级完全一致仍待原站登录态核对。新增交互检查 8/8 通过，见 qa/v02-tests.json；V0.1 的 34 项报告是历史报告，不代表本轮重跑。
