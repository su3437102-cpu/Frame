SpektraLab

在 Windows 电脑上冲洗、编辑和导出照片。工作台使用当前电脑的图形引擎，需先启动离线版。

打开本机工作台 ↗

打开浏览器冲洗工作台

首次使用

  1. 在支持 Vulkan 的 Windows x64 电脑上解压 SpektraLab-Windows离线网页版.zip。
  2. 双击 Launch-SpektraLab.cmd，保持启动窗口运行，再在同一台电脑上打开工作台。
  3. 导出完成后，在 FrameLab 用 Add image 或 Upload 将成片加入画布。

如果用了自定义端口，请打开启动窗口显示的网址。手机或另一台电脑打开入口时，需要在实际运行离线版的 Windows 电脑上操作。
