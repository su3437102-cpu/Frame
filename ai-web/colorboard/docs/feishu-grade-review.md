# 飞书样本调色整理

本页记录原批次分析。网站当前公开三套调色（绿金窗光、深绿林光、冰青留色）和基于 07.jpg 的「夜灯辉光」，其余三套已移出网页模板区。

从飞书导出的 18 张 1080×2348 截图裁出 26 张照片。编号沿用原文件名末尾数字。裁剪保留照片内容，移除手机状态栏、播放器、上下留黑和拼接外框。03、10、11 和 16 拆成调整前与调整后，05 拆成两张人像，17 拆成四张照片。对落在照片内的临时界面提示或对照字幕做局部修整，拟合时排除修整区域。原始文件保留在下载目录。

## 前后案例

- **03 楼梯窗光**。上图墙面较中性，楼梯和扶手受普通窗光照明。下图墙面偏奶油黄，楼梯和暗处偏橄榄绿，窗边高光发暖。
- **10 草地与耳机**。上图浅雾抬高植被黑位。下图压深树荫，焦点草地明显偏黄绿，天空强光和暗背景的反差更大。
- **11 水瓶与笔记本**。左图纸张、透明物和标贴较灰。右图提亮这些区域，草叶偏柔和橄榄灰绿，木面仍维持低调。
- **16 耳机与纸面**。左图纸面偏暗，背景草木颜色更集中。右图提升纸面和线材的层次，背景仍暗，略有不同裁幅和视角，先完成配准再纳入共享模板。

02 和 04 是同一水景的不同视角。05 是两张不同姿势的闪光人像，17 是四个画面的拼接。它们用于归类参考。六套模板均是固定的全局色彩映射。原例里的柔焦、逆光光晕和空间选择性调整可能需要在工作台上另做。冰青留色按颜色范围生效，如需只保留某个水域，可以结合手动蒙版。

配准后将画面分块，留出部分像素检验颜色拟合。以 8 位 RGB 平均绝对误差为单位（越低越接近调整后参考），03 从 28.25 降至 12.60，10 从 22.58 降至 7.75，11 从 24.22 降至 4.59，16 从 24.49 降至 4.34。这些数字只描述当前四组案例的整体颜色，原始记录见 `tools/feishu-pair-analysis.json`。
